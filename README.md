# 🎮 Number Guessing Game

A simple and interactive number guessing game built using JavaScript.

## Features
- Random number generation
- Custom maximum number
- 5 attempts limit
- Helpful hints (Too High / Too Low)
- Invalid input handling
- Quit option
- Play Again option

## Technologies Used
- JavaScript

## Concepts Practiced
- Variables and Data Types
- Conditional Statements
- Loops
- Break and Continue
- Type Conversion
- Boolean Logic
- Math.random() and Math.floor()

## How to Play
1. Enter the maximum number.
2. Guess the randomly generated number.
3. Follow the hints to find the correct number.
4. You get 5 attempts.
5. Play again after finishing the game.
